\begin{abstract}
The deployment of autonomous multi-agent swarms operating over shared enterprise transactional databases introduces a fundamental concurrency crisis. Unlike classical database transactions characterized by sub-millisecond compiled SQL queries, autonomous agents exhibit high-latency semantic reasoning phases (250~ms to 2,500~ms per step; 500~ms to 5,000~ms across multi-step workflows) while evaluating state-dependent domain policies, invoking external compliance tools, and executing multi-step LLM prompts within active critical sections. Under standard Strict Two-Phase Locking (S2PL), overlapping multi-resource lock acquisitions generate closed cycles in the system's Wait-For-Graph ($\mathcal{G}_{\text{wait}}$), while timestamp-based prevention (Wait-Die, Wound-Wait) and Optimistic Concurrency Control (OCC) trigger frequent mid-execution or commit-time aborts. Crucially, in multi-agent swarms, transaction aborts induce severe \textit{livelock token thrashing}, as aborted agents re-execute stochastic planning paths and discard hundreds to thousands of already-billed LLM inference tokens.

To resolve this systems bottleneck within a centralized shared-memory transactional lock coordinator or connection-pool gateway fronting an OLTP engine (such as a single Spanner Paxos group leader's local lock table), we present the \textbf{Epistemic Priority Ceiling Protocol (EPCP)}, an autonomous, invariant-preserving, provably deadlock-free concurrency control architecture. EPCP establishes a monotonically latched dynamic priority metric $\tilde{\Pi}_i(t)$ incorporating agent task tree depth, accumulated LLM token investment with aging, and inverse epistemic entropy, paired with a static upper-envelope preemption level $\Pi_i^{\max}$ over exact 64-bit integer lexicographical priority tuples. By maintaining fine-grained 64-partition intent-footprint priority ceilings and enforcing a guarded preemptive admission invariant ($\Pi_i^{\text{eff}}(t) > C_{-A_i}^*(t; \mathcal{F}(T_i))$), EPCP serializes admission across intersecting dynamic footprints before critical sections are entered while allowing disjoint footprints to execute in parallel without aborting in-flight transactions. We provide a rigorous inductive proof establishing that $\mathcal{G}_{\text{wait}}(t)$ remains a directed acyclic graph (DAG) under all thread interleavings. We implemented EPCP natively on macOS Apple Silicon and benchmarked sustained multi-threaded database transactions over an enterprise banking and supply chain schema (10,000 Accounts, 5,000 Inventory Items) under heavy Zipfian access skew ($\theta = 0.85$) across sub-millisecond cryptographic HMAC-SHA256 stress tests, 500~ms--1,500~ms multi-step LLM reasoning benchmarks, and live Google Cloud Vertex AI \texttt{gemini-2.5-flash} multi-agent runs against S2PL, 2PL-Wait Promote, Wound-Wait, Wait-Die, OCC, Coarse Shard-Scoped C2PL, and Canonical Ordered Locking. Empirical results demonstrate that EPCP achieves a \textbf{0.00\% deadlock and concurrency abort rate} across all regimes, completely eliminating victim transaction rollbacks while preserving strict conflict serializability and physical ACID integrity.
\end{abstract}

\section{Introduction}
\IEEEPARstart{E}{nterprise} cloud platforms are undergoing a paradigm shift from human-in-the-loop task execution to autonomous multi-agent systems. Built on orchestration frameworks such as Google Agent Development Kit (ADK) and Vertex AI Agent Builder, autonomous agent swarms are delegated end-to-end responsibilities over core enterprise workflows, including supply chain reconciliation, automated loan underwriting, financial clearing, and algorithmic procurement. In these architectures, multiple autonomous agents execute concurrently through a centralized shared-memory transactional lock coordinator or connection-pool gateway fronting shared OLTP database engines such as a single Google Cloud Spanner Paxos group leader~\cite{corbett2013spanner}, AlloyDB/PostgreSQL, or CockroachDB (leaving decentralized cross-leader two-phase commit ceiling synchronization across geo-distributed consensus groups to future work).

\subsection{The Semantic Reasoning Latency Expansion and Why Locks Span Inference}
Classical transaction processing was developed under the assumption that transactions are short-lived, pre-compiled SQL queries with execution latencies on the order of 100 microseconds to 5 milliseconds~\cite{gray1992transaction, bernstein1987concurrency}. Under this microsecond regime, locking protocols such as Strict Two-Phase Locking (S2PL)~\cite{eswaran1976notions} provide conflict serializability with negligible lock contention windows.

In autonomous multi-agent architectures, however, transactions are inherently interleaved with \textit{state-dependent semantic reasoning loops}. A natural question is whether holding locks across LLM inference can be avoided altogether via (i) snapshot reads followed by short compare-and-swap (CAS) / Optimistic Concurrency Control (OCC) validation at commit, (ii) simple commutative escrow columns (e.g., \texttt{reserved\_amount}), or (iii) Saga-based non-isolated sub-transactions~\cite{chang2025sagallm}. In regulated enterprise workflows, each of these alternatives breaks down under high contention:
\begin{enumerate}
    \item \textbf{Failure of Snapshot-Read + CAS and Scalar Escrow on Non-Commutative State Mutations:} While simple scalar decrements can use commutative escrow counters, enterprise agent workflows perform \textit{non-commutative, multi-attribute structural mutations}---such as corporate loan covenant restructuring, cross-collateralized margin re-indexing, and serialized lot compliance---where Step 2's multi-turn LLM synthesis, AML polynomial risk scoring, and generated SQL/JSON compliance patch depend nonlinearly on the exact vector of row attributes read in Step 1. When an agent acquires a pessimistic lock on $R_a$, it first runs an immediate sub-microsecond scalar sufficiency pre-filter (\texttt{Biz-Rule Reject}) to fast-exit obviously depleted accounts or out-of-stock SKUs with zero wasted LLM tokens; for funded rows passing this pre-filter, the subsequent $\text{Infer}(\phi)$ phase evaluates the full multi-attribute state of $R_a$. Under snapshot-read + CAS (OCC), if any contending agent modifies $R_a$ during the 500~ms--5,000~ms multi-step reasoning window, the generated compliance patch is invalidated and CAS fails at commit time \textit{after 100\% of the multi-step LLM token budget has already been expended}. Holding a pessimistic lock across $\text{Infer}(\phi)$ protects funded rows from mid-inference invalidation.
    \item \textbf{Prohibition of Uncommitted State Exposure:} Saga-based agent workflows~\cite{chang2025sagallm} release locks early by committing intermediate sub-transactions and relying on reverse compensating actions upon failure. However, in strict double-entry banking and regulatory clearing, exposing transient intermediate states to concurrent readers violates strict serializability and triggers cascading audit exceptions.
\end{enumerate}
Consequently, preserving strict ACID isolation without post-hoc validation rollbacks on non-commutative multi-attribute workflows requires holding pessimistic locks across intermediate reasoning phases, expanding lock retention durations from milliseconds to several seconds (500~ms to 5,000~ms)---a $10^3\times$ to $10^4\times$ duration expansion.

\subsection{The Livelock and Token Thrashing Crisis}
When agents acquire locks across multiple resources in dynamic orderings (e.g., Agent $A_1$ acquiring Account $\to$ Inventory while Agent $A_2$ acquires Inventory $\to$ Account), Wait-For-Graph ($\mathcal{G}_{\text{wait}}$) cycles form rapidly. Under S2PL, deadlock detection modules identify cycles and forcibly abort a ``victim'' transaction~\cite{gray1992transaction}. Similarly, classical timestamp-ordered deadlock prevention schemes~\cite{rosenkrantz1978system} avoid cycles by aborting transactions whenever timestamp inversions occur: under non-preemptive \textit{Wait-Die}, a younger requester immediately ``dies'' (aborts) upon encountering an older lock holder while an older requester waits; under preemptive \textit{Wound-Wait} (used in Google Cloud Spanner~\cite{corbett2013spanner}), an older requester immediately ``wounds'' (preemptively aborts) a younger lock holder while a younger requester waits.

In traditional relational databases, aborting an in-memory SQL transaction incurs minimal penalty. In multi-agent swarms, however, aborting an in-flight agent transaction---whether via S2PL deadlock victim selection, Wait-Die self-abort, Wound-Wait preemption~\cite{rosenkrantz1978system}, or OCC validation failure---results in \textbf{catastrophic token thrashing}:
\begin{itemize}
    \item \textbf{Token \& Financial Waste:} An agent rolled back mid-workflow loses its in-flight transactional state, discarding hundreds to thousands of already-billed LLM inference tokens (e.g., on Gemini 2.5 Pro / Flash endpoints).
    \item \textbf{Stochastic Lock Retrying:} Upon restart, the agent re-evaluates prompts against mutated state, frequently re-colliding with contending agents.
    \item \textbf{System Saturation:} Under heavy partition skew, abort-based concurrency controllers suffer persistent rollback cascades.
\end{itemize}

Real-time concurrency control offers foundational mechanisms for deadlock-free execution without victim aborts. Priority Inheritance and Priority Ceiling Protocols (PCP) were pioneered by Sha, Rajkumar, and Lehoczky~\cite{sha1990priority} for uniprocessor tasks with static priorities, and extended to dynamic-priority real-time tasks (such as Earliest Deadline First) by Chen and Lin's Dynamic Priority Ceiling Protocol~\cite{chen1990dynamic} and Baker's Stack Resource Policy (SRP)~\cite{baker1991stack}, which decouple static resource preemption levels from dynamic task urgency. In real-time databases, Abbott and Garcia-Molina~\cite{abbott1992scheduling} evaluated priority-cognizant 2PL variants---\textit{2PL-High Priority} (which aborts lower-priority lock holders, inducing token waste) and \textit{2PL-Wait Promote} (which applies priority inheritance upon direct row lock conflicts). Crucially, because \textit{2PL-Wait Promote} lacks a preemptive partition priority ceiling admission gate, transactions still acquire initial locks in opposing orders and suffer multi-resource $\mathcal{G}_{\text{wait}}$ deadlocks. In parallel, classical database deadlock prevention via Conservative 2PL (C2PL)~\cite{bernstein1987concurrency}, canonical ordered locking, or deterministic scheduling such as Calvin~\cite{thomson2012calvin} requires transactions to either pre-declare and lock every exact row key upfront or sort all target row IDs prior to acquiring any lock. However, in multi-step agentic workflows, the fine-grained target row key $R_b$ in Step 2 (e.g., which specific warehouse lot or counterparty ledger row to debit) is discovered dynamically from the output of Step 1's LLM inference $\text{Infer}(\phi)$, making exact row-level C2PL or upfront canonical row sorting impossible without either locking coarse domain shards exclusively or running an unisolated speculative discovery pre-pass. Recent agentic concurrency frameworks---including SagaLLM~\cite{chang2025sagallm} for compensating workflows, ATCC~\cite{zhou2026atcc} (which adaptively switches LLM agent transactions between optimistic and pessimistic concurrency control based on conflict rates), and CoAgent~\cite{lyu2026coagent} (which co-designs multi-agent execution scheduling and database concurrency control)---improve agent throughput under contention, but rely on optimistic/pessimistic aborts or schedule reordering rather than a provably deadlock-free, non-aborting priority ceiling protocol coupled to live LLM token investment and epistemic action entropy.

\subsection{Contributions}
In this work, we present the \textbf{Epistemic Priority Ceiling Protocol (EPCP)}, an autonomous, invariant-preserving (in the concurrency-control sense of maintaining cycle-free wait invariants dynamically without background deadlock detectors or victim aborts) concurrency control architecture engineered for high-latency semantic agent transactions. Our primary contributions are:
\begin{enumerate}
    \item \textbf{Dual-Level Epistemic Priority Architecture ($\Pi_i^{\max}$ and $\tilde{\Pi}_i(t)$):} A formal priority formulation coupling task delegation depth ($d_i$), clipped cumulative token and aging expenditure ($\Omega_i(t)$), and inverse normalized token-level Shannon action entropy ($1 - \mathcal{H}_i(t)$, where $\mathcal{H}_i(t) \in [0, 1]$ measures action distribution uncertainty), represented as exact 64-bit integer lexicographical tuples to guarantee strict total ordering without floating-point precision loss.
    \item \textbf{Intersecting-Footprint Partition Priority Ceilings ($C_{-A_i}^*(t; \mathcal{F}(T_i))$):} A 64-partition lock admission invariant where an agent declares an ADK routing-header hash footprint $\mathcal{F}(T_i) \subseteq \{1, \dots, 64\}$ at registration, serializing initial entry across intersecting dynamic footprints ($\mathcal{F}(T_i) \cap \mathcal{F}(T_k) \ne \emptyset$) to prevent Step-2 dynamic-discovery cycles while executing disjoint footprints ($\mathcal{F}(T_i) \cap \mathcal{F}(T_k) = \emptyset$) in full parallel concurrency.
    \item \textbf{Provable Deadlock Immunity (Theorem 1):} A rigorous inductive proof over unified contention and ceiling wait edges demonstrating that $\mathcal{G}_{\text{wait}}(t)$ remains a directed acyclic graph (DAG) at all times, guaranteeing a 0.00\% deadlock abort rate without victim selection.
    \item \textbf{Bounded Priority Inversion \& Starvation Freedom (Theorems 2 \& 3):} Proofs establishing per-partition single-critical-section inversion bounds via transitive priority inheritance and unconditional finite-time completion via atomic senior saturation promotion.
    \item \textbf{Comprehensive Empirical & Live Vertex AI Validation:} Multi-threaded benchmarks over an enterprise banking and supply chain schema (10,000 Accounts, 5,000 Inventory Items) under Zipfian skew ($\theta = 0.85$), spanning sub-millisecond HMAC-SHA256 stress tests (with Zero-Depletion Controls across $K \in \{20, 30, 40\}$), 500~ms--1,500~ms 2-step LLM reasoning benchmarks ($250\text{--}750\text{ ms}$/step across 9 protocols including \texttt{2PL-Wait Promote}), and live Google Cloud Vertex AI \texttt{gemini-2.5-flash} multi-agent evaluations on project \texttt{aniket-personal}.
\end{enumerate}

\section{System Model and Problem Formulation}

\subsection{Execution Environment and Intent-Scoped Footprints}
We consider a transactional database system $\mathcal{D}$ arbitrated by a centralized shared-memory lock coordinator (or a single Spanner Paxos group leader's local lock table~\cite{corbett2013spanner}) maintaining a set of shared row-level resources $\mathcal{R} = \{R_1, R_2, \dots, R_M\}$, mapped via a deterministic FNV-1a 64-bit hash function $\text{part} : \mathcal{R} \to \{1, \dots, B_{\text{part}}\}$ ($B_{\text{part}} = 64$) into fine-grained logical lock partitions. Each transaction's partition footprint is represented compactly as a single 64-bit unsigned integer bitmask (\texttt{uint64\_t}), enabling $O(1)$ hardware bitwise-\texttt{AND} footprint intersection checks. A swarm of $K$ autonomous agent worker threads $\mathcal{A} = \{A_1, A_2, \dots, A_K\}$ concurrently execute transactional tasks.

Unlike row-level C2PL (which requires knowing every exact row primary key $R_a, R_b$ before locking), EPCP requires only an \textbf{Intent-Scoped Partition Footprint} $\mathcal{F}(T_i) \subseteq \{1, \dots, B_{\text{part}}\}$ (typically $|\mathcal{F}(T_i)| \in \{2, 3\}$ out of $B_{\text{part}} = 64$), extracted statically from the mandatory routing metadata of the agent's ADK/MCP tool invocation schema (e.g., the 64-bucket hash IDs of the target customer account segment and warehouse SKU category). While $\mathcal{F}(T_i)$ is known at registration, the exact fine-grained row keys $R_a, R_b \in \mathcal{R}$ within $\mathcal{F}(T_i)$ are discovered dynamically during execution:
\begin{equation}
\label{eq:tx_model}
\begin{aligned}
T_i = \langle &\text{Register}(\mathcal{F}(T_i)),\, \text{Lock}(R_a),\, \text{BizCheck}(R_a),\, \text{Infer}(\phi), \\
&\text{StageWrite}(R_a),\, \text{Lock}(R_b),\, \dots,\, \text{Commit} \rangle
\end{aligned}
\end{equation}
where $\text{Infer}(\phi)$ denotes parameterized LLM policy inference (using $\phi$ to distinguish model parameters from the Zipfian skew parameter $\theta$), and $\text{StageWrite}(R_a)$ stages mutations in a transaction-local write buffer that is only flushed atomically to physical database storage at $\text{Commit}$ after all locks are held. If an agent ever attempts to request an out-of-footprint resource $R_{\text{req}}$ with $\text{part}(R_{\text{req}}) \notin \mathcal{F}(T_i)$, the coordinator rejects the lock call, discards the uncommitted local write buffer (so zero physical database rollback is required), memoizes completed $\text{Infer}(\phi)$ outputs in the agent's local context cache keyed by a cryptographic SHA-256 digest of the read attributes of $R_a$ (\texttt{state\_version\_digest}), releases held locks, expands $\mathcal{F}(T_i) \leftarrow \mathcal{F}(T_i) \cup \{\text{part}(R_{\text{req}})\}$, and re-registers \textit{while preserving its original arrival timestamp $t_{\text{start},i}$ and monotonic rank $\text{rank}(T_i)$}. Upon re-acquiring $R_a$, if $R_a$'s attributes are unchanged (matching \texttt{state\_version\_digest}), the memoized inference output is replayed in microseconds with \textbf{zero re-billed LLM tokens}; if $R_a$ was modified by another transaction during the brief unlock window, the SHA-256 digest misses and $\text{Infer}(\phi)$ is freshly re-evaluated against the new state (in our evaluated ADK banking and supply-chain tool schemas, routing headers bound 100\% of candidate partitions upfront, so footprint expansion is never triggered).

\subsection{Unified Wait-For-Graph and Deadlock Formalization}
Let $\text{Held}(A_j, t) \subseteq \mathcal{R}$ denote the set of resources currently locked by agent $A_j$ at time $t$.

\begin{definition}[Unified Wait-For-Graph]
The Unified Wait-For-Graph at time $t$, denoted $\mathcal{G}_{\text{wait}}(t) = (\mathcal{V}, \mathcal{E}(t))$, is a directed graph where vertices $\mathcal{V} = \mathcal{A}$ represent active agent worker threads, and a directed edge $(A_i \to A_j) \in \mathcal{E}(t)$ ($i \ne j$) exists if and only if agent $A_i$ is currently suspended awaiting lock acquisition on resource $R_{\text{req}}$ ($\text{part}(R_{\text{req}}) \in \mathcal{F}(T_i)$) because:
\begin{enumerate}
    \item \textbf{Direct Contention Wait:} $R_{\text{req}} \in \text{Held}(A_j, t)$; or
    \item \textbf{Ceiling Preemption Wait:} $R_{\text{req}}$ is free, Eq.~\eqref{eq:ceiling_rule} fails for $A_i$, and $A_j$ ($j \ne i$) is an active lock holder ($\text{Held}(A_j, t) \ne \emptyset$) with an intersecting partition footprint ($\mathcal{F}(T_i) \cap \mathcal{F}(T_j) \ne \emptyset$) whose shared partition ceiling blocks $A_i$'s admission ($\max_{P_m \in \mathcal{F}(T_i) \cap \mathcal{F}(T_j)} \Pi(P_m, t) \ge \Pi_i^{\text{eff}}(t)$).
\end{enumerate}
\end{definition}

\begin{definition}[Deadlock State]
A system is in a deadlock state at time $t$ if and only if there exists a directed cycle in $\mathcal{G}_{\text{wait}}(t)$:
\begin{equation}
A_{p_1} \to A_{p_2} \to \dots \to A_{p_L} \to A_{p_1}
\end{equation}
Under S2PL, resolving this cycle requires selecting a victim agent $A_{p_v}$ and aborting its transaction, rolling back uncommitted writes and discarding in-flight LLM reasoning tokens.
\end{definition}

\section{The Epistemic Priority Ceiling Protocol}

\subsection{Monotonically Latched Epistemic Priority Formulation}
Unlike classical real-time operating systems where thread priorities are static integers~\cite{sha1990priority, baker1991stack}, autonomous agent priorities must reflect both the economic sunk cost and epistemic certainty of in-flight reasoning tasks while remaining strictly ordered and non-decreasing during an active transaction. Following Baker's SRP principle~\cite{baker1991stack}, EPCP maintains two complementary priority quantities per transaction $T_i$: (1) a static \textbf{Transaction Upper-Envelope Preemption Level} $\Pi_i^{\max}$ (determined at registration by task depth $d_i$ and arrival rank $\text{rank}(T_i)$) that defines invariant partition ceilings so ceilings never shift mid-lock and cause self-deadlock, and (2) a live \textbf{Monotonically Latched Dynamic Priority} $\tilde{\Pi}_i(t)$ (driven by real-time token expenditure $\text{Tokens}_i(t)$, wait-time aging, and action certainty $1 - \mathcal{H}_i(t)$) that orders condition-variable wake-up queues and dynamic urgency scheduling among waiting agents. Thus, when a lock holder commits and signals blocked waiters, the waiting agent with the highest live epistemic investment $\tilde{\Pi}_k^{\text{eff}}(t)$ is dispatched first to acquire the released resource.

\begin{definition}[Dynamic and Latched Epistemic Priority]
At time $t$, the instantaneous epistemic score $\Pi_i(t) \in \mathbb{R}^+$ of agent $A_i$ executing transaction $T_i$ (started at $t_{\text{start},i}$) is:
\begin{equation}
\Pi_i(t) \triangleq \Pi_{\text{base}} + w_d \cdot d_i + w_\Omega \cdot \ln(1 + \Omega_i(t)) + w_c \cdot (1 - \mathcal{H}_i(t))
\end{equation}
where $\Pi_{\text{base}} = 1.0$, $d_i \in \{1, \dots, d_{\max}\}$ ($d_{\max} = 4$) is the agent call-graph delegation depth, and $\Omega_i(t)$ combines cumulative LLM token investment with linear wait-time aging ($\gamma_{\text{age}} = 0.05\text{ s}^{-1}$, explicitly clipped at $\Omega_{\max} = 10^4$):
\begin{equation}
\Omega_i(t) \triangleq \min\!\left(\Omega_{\max},\, \frac{\text{Tokens}_i(t)}{100} + \gamma_{\text{age}}(t - t_{\text{start},i})\right)
\end{equation}
with $\Omega_i(t) \in [0, \Omega_{\max}]$. The normalized token-level Shannon entropy $\mathcal{H}_i(t) \in [0, 1]$ over the agent's candidate tool-action distribution $p_{i,t}(v)$ ($v \in \mathcal{V}_{\text{act}}$, extracted from the softmax log-probabilities of the LLM's structured tool-call head at time $t$, initialized to neutral uncertainty $\mathcal{H}_i(t_{\text{start},i}) = 0.5$ prior to the first inference step) is defined as:
\begin{equation}
\mathcal{H}_i(t) \triangleq \begin{cases}
0, & \text{if } |\mathcal{V}_{\text{act}}| \le 1, \\
-\frac{1}{\ln |\mathcal{V}_{\text{act}}|}\sum_{v \in \mathcal{V}_{\text{act}}} p_{i,t}(v)\ln p_{i,t}(v), & \text{if } |\mathcal{V}_{\text{act}}| > 1,
\end{cases}
\end{equation}
with weights fixed at $w_d = 2.0, w_\Omega = 1.5, w_c = 3.0$ (chosen so one delegation level $w_d = 2.0$ outweighs cold-start entropy variance while full epistemic certainty $w_c = 3.0$ and log-token investment $w_\Omega \ln(1+\Omega_i(t)) \in [0, 13.82]$ dominate mid-flight urgency; sensitivity sweeps across $\pm 50\%$ weight perturbations preserve $0.00\%$ aborts with $< 2.1\%$ goodput variation). Furthermore, to guarantee unconditional starvation freedom across arbitrary depths (Theorem 3), if a waiting transaction's age reaches the senior saturation horizon $T_{\text{sat}} = \Omega_{\max}/\gamma_{\text{age}}$, its latched score AND its upper-envelope preemption score are atomically promoted to the uniform saturation ceiling $\Pi_{\text{sat}} \triangleq \Pi_{\text{base}} + w_d \cdot d_{\max} + w_\Omega \cdot \ln(1 + \Omega_{\max}) + w_c$, updating $\Pi(P_m, t)$ for all $P_m \in \mathcal{F}(T_i)$ and immediately propagating the promoted priority to any blocking holders via Eq.~\eqref{eq:inheritance}.

Let $\Pi_i^{\text{score}}(t) \triangleq \max_{\tau \in [t_{\text{start},i}, t]} \Pi_i(\tau)$ denote the monotonically latched dynamic score and $\Pi_{i,\max}^{\text{score}} \triangleq \Pi_{\text{base}} + w_d d_i + w_\Omega \ln(1 + \Omega_{\max}) + w_c$ (upgraded to $\Pi_{\text{sat}}$ if $t - t_{\text{start},i} \ge T_{\text{sat}}$) denote the upper-envelope preemption score. To eliminate IEEE-754 floating-point mantissa precision loss or negativity as the monotonic arrival sequence ID $\text{rank}(T_i) \in \mathbb{N}$ grows over millions of transactions, the coordinator represents priorities internally as exact 64-bit integer lexicographical pairs $\tilde{\mathbf{\Pi}}_i(t) = \big(\lfloor 10^6 \Pi_i^{\text{score}}(t)\rfloor,\, -\text{rank}(T_i)\big)$ and $\mathbf{\Pi}_i^{\max} = \big(\lfloor 10^6 \Pi_{i,\max}^{\text{score}}\rfloor,\, -\text{rank}(T_i)\big) \in \mathbb{Z}_{\ge 0} \times \mathbb{Z}_{< 0}$ (and rebases $\text{rank}(T_i) \leftarrow 1$ whenever $\mathcal{A}_{\text{active}}(t) = \emptyset$). In scalar notation, we write this strict lexicographical order via the tie-breaker $\epsilon_{\text{tie}} = 10^{-7}$ as the \textbf{Monotonically Latched Dynamic Priority} $\tilde{\Pi}_i(t)$ and the \textbf{Transaction Upper-Envelope Preemption Level} $\Pi_i^{\max}$:
\begin{align}
\tilde{\Pi}_i(t) &\triangleq \Pi_i^{\text{score}}(t) - \epsilon_{\text{tie}} \cdot \text{rank}(T_i), \\
\Pi_i^{\max} &\triangleq \Pi_{i,\max}^{\text{score}} - \epsilon_{\text{tie}} \cdot \text{rank}(T_i)
\end{align}
By construction, for all $t_1 \le t_2$ during $T_i$'s execution, $0 < \tilde{\Pi}_i(t_1) \le \tilde{\Pi}_i(t_2) \le \Pi_i^{\max}$, and $\Pi_i^{\max} \ne \Pi_j^{\max}$ for all $i \ne j$.
\end{definition}

\subsection{Atomic Registration and Intersecting-Footprint Partition Ceilings}
Let $\mathcal{A}_{\text{active}}(t)$ denote the set of registered active transactions at time $t$. In EPCP, $\text{Register}(\mathcal{F}(T_q))$ and $T_q$'s initial lock check $\text{Lock}(R_a)$ execute as a \textbf{single atomic critical section under the coordinator mutex}: when $T_q$ arrives at time $t_{\text{arr}}$ with declared footprint $\mathcal{F}(T_q)$, $T_q$ is inserted into $\mathcal{A}_{\text{active}}(t)$ and into $\mathcal{U}(P_m, t) \triangleq \{A_r \in \mathcal{A}_{\text{active}}(t) \mid P_m \in \mathcal{F}(T_r)\}$ for all $P_m \in \mathcal{F}(T_q)$ (elevating each partition ceiling $\Pi(P_m, t)$ via the exact 64-bit integer tuple comparison $\mathbf{\Pi}_q^{\max}$), and immediately evaluates Eq.~\eqref{eq:ceiling_rule} for $R_a$. If any active lock holder $A_k$ ($\text{Held}(A_k, t_{\text{arr}}) \ne \emptyset$) has an intersecting footprint $\mathcal{F}(T_k) \cap \mathcal{F}(T_q) \ne \emptyset$, $T_q$ atomically binds ceiling wait edges $(A_q \to A_k)$ for all $A_k \in \mathcal{B}_{\text{ceil}}(A_q, t_{\text{arr}})$ and propagates $\Pi_q^{\max}$ to $A_k$ via transitive priority inheritance (Eq.~\eqref{eq:inheritance}) before releasing the coordinator mutex to sleep on $\text{CV}_{\text{ceil}}$.

\begin{definition}[Partition Ceiling and Intersecting-Footprint System Ceiling]
For each logical partition $P_m \in \{1, \dots, B_{\text{part}}\}$, the partition priority ceiling $\Pi(P_m, t)$ (and resource ceiling $C(R_j, t) \triangleq \Pi(\text{part}(R_j), t)$) is the maximum upper-envelope preemption bound among all active transactions registered for partition $P_m$:
\begin{equation}
\label{eq:part_ceiling_def}
\Pi(P_m, t) \triangleq \max \Big( \{0\} \cup \big\{ \Pi_q^{\max} \;\big|\; A_q \in \mathcal{U}(P_m, t) \big\} \Big)
\end{equation}
Because $\Pi(P_m, t)$ is computed over the upper-envelope $\Pi_q^{\max}$ of registered agents, $\Pi(P_m, t) \ge \tilde{\Pi}_q(\tau)$ holds for every $A_q \in \mathcal{U}(P_m, t)$ at all instants $\tau$. For an agent $A_i$ with footprint $\mathcal{F}(T_i)$, let $\mathcal{K}_{\text{ext}}(A_i, t) \triangleq \{A_k \in \mathcal{A}_{\text{active}}(t) \setminus \{A_i\} \mid \text{Held}(A_k, t) \ne \emptyset \;\land\; \mathcal{F}(T_k) \cap \mathcal{F}(T_i) \ne \emptyset\}$ denote the set of active \textit{external} lock-holding agents whose declared partition footprint intersects $\mathcal{F}(T_i)$. The \textbf{External Intersecting-Footprint System Ceiling} $C_{-A_i}^*(t; \mathcal{F}(T_i))$ and the \textbf{Overall Intersecting-Footprint System Ceiling} $C^*(t; \mathcal{F}(T_i))$ are defined as:
\begin{align}
\label{eq:ext_ceiling_def}
C_{-A_i}^*(t; \mathcal{F}(T_i)) &\triangleq \max \Big( \{0\} \cup \big\{ \Pi(P_m, t) \;\big|\; A_k \in \mathcal{K}_{\text{ext}}(A_i, t), \nonumber \\
&\qquad\quad P_m \in \mathcal{F}(T_i) \cap \mathcal{F}(T_k) \big\} \Big), \\
\label{eq:overall_ceiling_def}
C^*(t; \mathcal{F}(T_i)) &\triangleq \max \Big( \{0\} \cup \big\{ \Pi(P_m, t) \;\big|\; A_k \in \mathcal{A}_{\text{active}}(t), \nonumber \\
&\qquad\quad \text{Held}(A_k, t) \ne \emptyset,\, P_m \in \mathcal{F}(T_i) \cap \mathcal{F}(T_k) \big\} \Big)
\end{align}
Notice two fundamental properties of Eq.~\eqref{eq:ext_ceiling_def}:
\begin{enumerate}
    \item \textbf{Parallel Concurrency Across Disjoint 64-Bucket Footprints ($\mathcal{K}_{\text{ext}}(A_i, t) = \emptyset$):} Whenever no external lock-holding transaction has a footprint intersecting $\mathcal{F}(T_i)$ ($\mathcal{K}_{\text{ext}}(A_i, t) = \emptyset$, e.g., when concurrent agents operate on non-overlapping hash buckets across $B_{\text{part}} = 64$), Eq.~\eqref{eq:ext_ceiling_def} takes the maximum over the empty set and yields $C_{-A_i}^*(t; \mathcal{F}(T_i)) = 0 < \Pi_i^{\text{eff}}(t)$. Thus, $A_i$ never self-blocks on its own registration in $\mathcal{U}(P_m, t)$ and enters immediately in parallel with all disjoint-footprint transactions.
    \item \textbf{Intersecting-Footprint Admission Exclusion ($\mathcal{K}_{\text{ext}}(A_i, t) \ne \emptyset$):} Because $A_i \in \mathcal{U}(P_m, t)$ for all $P_m \in \mathcal{F}(T_i)$, whenever an external transaction $A_k \in \mathcal{K}_{\text{ext}}(A_i, t)$ already holds any lock ($\text{Held}(A_k, t) \ne \emptyset$) and shares at least one partition $P_{\text{shared}} \in \mathcal{F}(T_i) \cap \mathcal{F}(T_k)$, Eq.~\eqref{eq:ext_ceiling_def} yields $C_{-A_i}^*(t; \mathcal{F}(T_i)) \ge \Pi(P_{\text{shared}}, t) \ge \max(\Pi_i^{\max}, \Pi_k^{\max}) \ge \Pi_i^{\max}$. Because Step-2 row keys inside $\mathcal{F}(T_i)$ are discovered dynamically during Step-1 LLM inference, this intentionally enforces \textbf{single-holder admission exclusion across intersecting footprints}: a newly arriving $A_i$ ($\text{Held}(A_i, t) = \emptyset$, even if $\Pi_i^{\max} > \Pi_k^{\max}$) is suspended at the admission gate $\text{CV}_{\text{ceil}}(P_{\text{shared}})$ rather than entering $P_{\text{shared}}$ concurrently with $A_k$ (which would risk $A_i$ and $A_k$ dynamically discovering and requesting each other's held rows in Step 2), and instead immediately elevates $A_k$ via transitive priority inheritance ($\Pi_k^{\text{eff}}(t) \leftarrow \max(\Pi_k^{\text{eff}}(t), \Pi_i^{\max})$) so $A_k$ completes its remaining steps rapidly and hands the footprint to $A_i$.
\end{enumerate}
\end{definition}

\subsection{EPCP Resource Allocation and Guarded Pass-Through Rules}
When agent $A_i$ requests lock acquisition on resource $R_{\text{req}}$ ($\text{part}(R_{\text{req}}) \in \mathcal{F}(T_i)$) at time $t$ (summarized in Algorithm~\ref{alg:epcp}):
\begin{enumerate}
    \item \textbf{Reentrancy:} If $R_{\text{req}} \in \text{Held}(A_i, t)$, access is granted immediately.
    \item \textbf{Contention Suspension:} If $R_{\text{req}} \in \text{Held}(A_j, t)$ ($j \ne i$), $A_i$ is suspended on $\text{CV}(R_{\text{req}})$ and directed edge $(A_i \to A_j)$ is added to $\mathcal{G}_{\text{wait}}(t)$.
    \item \textbf{Ceiling Admissibility \& Guarded Inheritance Pass-Through Rule:} If $R_{\text{req}}$ is currently free, $A_i$ is granted the lock \textbf{if and only if}:
    \begin{equation}
    \label{eq:ceiling_rule}
    \begin{aligned}
    \Pi_i^{\text{eff}}(t) &> C_{-A_i}^*(t; \mathcal{F}(T_i)) \\
    &\lor \Big( \Pi_i^{\text{eff}}(t) = C^*(t; \mathcal{F}(T_i)) \land \text{Held}(A_i, t) \ne \emptyset \\
    &\quad \land \big[\Pi_i^{\text{eff}}(t) > \Pi_i^{\max} \\
    &\qquad \lor \Pi_i^{\max} = C^*(t; \mathcal{F}(T_i))\big] \Big)
    \end{aligned}
    \end{equation}
    The explicit guard $\text{Held}(A_i, t) \ne \emptyset$ in the second disjunct ensures that an agent entering its critical section for the first time ($\text{Held}(A_i, t) = \emptyset$) \textit{must} satisfy the strict inequality $\Pi_i^{\text{eff}}(t) > C_{-A_i}^*(t; \mathcal{F}(T_i))$ (which holds if and only if $\mathcal{K}_{\text{ext}}(A_i, t) = \emptyset$). Conversely, once $A_i$ already holds its initial lock ($\text{Held}(A_i, t) \ne \emptyset$) and either uniquely owns the top ceiling $\Pi_i^{\max} = C^*(t; \mathcal{F}(T_i))$ or has inherited $\Pi_i^{\text{eff}}(t) = C^*(t; \mathcal{F}(T_i)) > \Pi_i^{\max}$ from a ceiling-blocked waiter $A_q$, the guarded pass-through clause permits $A_i$ to acquire its Step-2 locks within $\mathcal{F}(T_i)$ without self-blocking. If Eq.~\eqref{eq:ceiling_rule} fails, let $\mathcal{B}_{\text{ceil}}(A_i, t) \triangleq \{A_j \in \mathcal{K}_{\text{ext}}(A_i, t) \mid \max_{P_m \in \mathcal{F}(T_i) \cap \mathcal{F}(T_j)} \Pi(P_m, t) \ge \Pi_i^{\text{eff}}(t)\}$ be the non-empty set of external ceiling-blocking lock holders; $A_i$ is suspended on $\text{CV}_{\text{ceil}}(P_m)$ and directed wait edges $(A_i \to A_j)$ are recorded in $\mathcal{G}_{\text{wait}}(t)$ for all $A_j \in \mathcal{B}_{\text{ceil}}(A_i, t)$ (matching Definition 1(2)).
\end{enumerate}

\begin{algorithm}[t]
\caption{EPCP Atomic Lock Acquisition \& Release}
\label{alg:epcp}
\begin{algorithmic}[1]
\small
\STATE \textbf{Procedure} $\textsc{AcquireLock}(A_i, R_{\text{req}})$ \textbf{under Coordinator Mutex:}
\IF{$\text{part}(R_{\text{req}}) \notin \mathcal{F}(T_i)$}
    \STATE Discard local staged writes; release $\text{Held}(A_i, t)$; expand $\mathcal{F}(T_i) \leftarrow \mathcal{F}(T_i) \cup \{\text{part}(R_{\text{req}})\}$ preserving $(t_{\text{start},i}, \text{rank}(T_i))$
\ENDIF
\LOOP
    \IF{$t - t_{\text{start},i} \ge T_{\text{sat}}$}
        \STATE Promote $\tilde{\Pi}_i(t), \Pi_i^{\max} \leftarrow \Pi_{\text{sat}} - \epsilon_{\text{tie}}\text{rank}(T_i)$; update $\Pi(P_m, t)$
    \ENDIF
    \IF{$R_{\text{req}} \in \text{Held}(A_i, t)$} \RETURN \TRUE \textbf{end if}
    \STATE Compute $C_{-A_i}^*(t; \mathcal{F}(T_i))$ and $C^*(t; \mathcal{F}(T_i))$ via 64-bit footprint masks
    \IF{$R_{\text{req}}$ is free \AND Eq.~\eqref{eq:ceiling_rule} holds}
        \STATE $\text{Held}(A_i, t) \leftarrow \text{Held}(A_i, t) \cup \{R_{\text{req}}\}$; clear outgoing $\mathcal{E}(A_i)$; \RETURN \TRUE
    \ENDIF
    \STATE Bind $(A_i \to A_j) \in \mathcal{E}(t)$ for holder of $R_{\text{req}}$ (Rule 2) or all $A_j \in \mathcal{B}_{\text{ceil}}(A_i, t)$ (Rule 3)
    \STATE Propagate $\Pi_i^{\text{eff}}(t)$ and $\tilde{\Pi}_i^{\text{eff}}(t)$ transitively along $\mathcal{G}_{\text{wait}}(t)$ via Eq.~\eqref{eq:inheritance}
    \STATE $\textsc{Wait}(\text{CV}(R_{\text{req}}) \text{ or } \text{CV}_{\text{ceil}}(P_m))$
\ENDLOOP
\STATE \textbf{Procedure} $\textsc{ReleaseAllLocks}(A_j)$ \textbf{at Commit / Biz-Rule Exit:}
\STATE Flush staged writes (if committing); release $\text{Held}(A_j, t)$; remove $A_j \in \mathcal{A}_{\text{active}}(t)$ and update $\Pi(P_m, t)$; wake waiters in descending order of $\tilde{\mathbf{\Pi}}_k^{\text{eff}}(t)$.
\end{algorithmic}
\end{algorithm}

\subsection{Unified Transitive Epistemic Priority Inheritance and Release Mechanics}
To prevent unbounded priority inversion under both Rule 2 (direct contention) and Rule 3 (ceiling preemption), let $\text{Waiters}(A_j, t) \triangleq \{A_k \in \mathcal{A} \mid (A_k \to A_j) \in \mathcal{E}(t)\}$ denote all agents directly or ceiling-blocked by resources held by $A_j$. The effective preemption priority $\Pi_j^{\text{eff}}(t)$ and effective dynamic urgency $\tilde{\Pi}_j^{\text{eff}}(t)$ of $A_j$ are maintained atomically:
\begin{align}
\label{eq:inheritance}
\Pi_j^{\text{eff}}(t) &\triangleq \max \left( \Pi_j^{\max},\, \max_{A_k \in \text{Waiters}(A_j, t)} \Pi_k^{\text{eff}}(t) \right), \\
\tilde{\Pi}_j^{\text{eff}}(t) &\triangleq \max \left( \tilde{\Pi}_j(t),\, \max_{A_k \in \text{Waiters}(A_j, t)} \tilde{\Pi}_k^{\text{eff}}(t) \right)
\end{align}
Whenever $A_i$ blocks on $A_j \in \mathcal{B}_{\text{ceil}}(A_i, t)$ (or via direct contention), $A_j$ immediately inherits both $\Pi_i^{\text{eff}}(t)$ (enabling guarded pass-through under Eq.~\eqref{eq:ceiling_rule}) and $\tilde{\Pi}_i^{\text{eff}}(t)$ transitively along any directed path in $\mathcal{G}_{\text{wait}}(t)$. Upon transaction commit (or clean \texttt{Biz-Rule Reject} exit), $A_j$ atomically releases all locks in $\text{Held}(A_j, t)$, removes itself from $\mathcal{A}_{\text{active}}(t)$---which deletes $A_j$ from $\mathcal{U}(P_m, t)$ and updates each partition max-heap $\Pi(P_m, t)$ for $P_m \in \mathcal{F}(T_j)$---removes all incoming edges $(A_k \to A_j) \in \mathcal{E}(t)$, and signals waiting threads on $\text{CV}(R_{\text{req}})$ and $\text{CV}_{\text{ceil}}(P_m)$ in descending order of live dynamic urgency $\tilde{\Pi}_k^{\text{eff}}(t)$. Maintaining per-partition max-heaps over $K$ threads alongside 64-bit integer footprint bitmasks (\texttt{uint64\_t} bitwise-\texttt{AND} overlap checks in $O(1)$ per active holder) bounds each lock/unlock operation to $\mathcal{O}(|\mathcal{F}(T_i)|\log K + K)$ time ($< 1.8\text{ }\mu\text{s}$ at $K=40, |\mathcal{F}(T_i)| \le 3$).

\section{Formal Theoretical Analysis}

\subsection{Theorem 1: Deadlock Elimination via Inductive Dynamic Acyclicity}
\begin{theorem}[Deadlock Elimination]
Under the Epistemic Priority Ceiling Protocol (EPCP), the Unified Wait-For-Graph $\mathcal{G}_{\text{wait}}(t)$ is a directed acyclic graph (DAG) for all times $t \ge 0$. Consequently, deadlocks are provably impossible, and the transaction abort rate due to deadlock is identically 0.00\%.
\end{theorem}

\begin{proof}
We prove Theorem 1 by contradiction using mathematical induction over the discrete sequence of lock acquisition and suspension events $0 = t_0 < t_1 < t_2 < \dots < t_N$.

\textbf{Base Case ($t=0$):} At system initialization, no locks are held and $\mathcal{E}(0) = \emptyset$, which is trivially acyclic.

\textbf{Inductive Hypothesis:} Assume that for all $t < t_k$, $\mathcal{G}_{\text{wait}}(t)$ is a directed acyclic graph (DAG).

\textbf{Inductive Step ($t = t_k$):} Suppose for the sake of contradiction that at event time $t_k$, a lock request by some agent closes a minimal directed cycle of length $L \ge 2$ in $\mathcal{G}_{\text{wait}}(t_k)$:
\begin{equation}
A_{p_1} \to A_{p_2} \to \dots \to A_{p_L} \to A_{p_1}
\end{equation}
where $\text{succ}(m) \triangleq (m \bmod L) + 1$. By Definition 1, every directed edge $(A_{p_m} \to A_{p_{\text{succ}(m)}}) \in \mathcal{E}(t_k)$ requires that $A_{p_{\text{succ}(m)}}$ is currently holding at least one lock ($\text{Held}(A_{p_{\text{succ}(m)}}, t_k) \ne \emptyset$) and that their declared partition footprints intersect:
\begin{equation}
\label{eq:footprint_overlap}
\mathcal{F}(T_{p_m}) \cap \mathcal{F}(T_{p_{\text{succ}(m)}}) \ne \emptyset, \quad \forall m \in \{1, \dots, L\}
\end{equation}

For each agent $A_{p_m}$ in the cycle, since $\text{Held}(A_{p_m}, t_k) \ne \emptyset$, let $t_{p_m}^{\text{entry}} < t_k$ denote the exact instant when $A_{p_m}$ transitioned from holding no locks ($\text{Held}(A_{p_m}, t_{p_m}^{\text{entry}-}) = \emptyset$) to acquiring the first of its currently held locks $R_{(p_m)}^{\text{first}}$. Because events are serialized by the coordinator mutex, entry timestamps are distinct; let $A_{p^*}$ ($p^* \in \{1, \dots, L\}$) be the unique agent in the cycle that entered its critical section latest in time:
\begin{equation}
t^* \triangleq t_{p^*}^{\text{entry}} = \max_{m \in \{1, \dots, L\}} t_{p_m}^{\text{entry}} < t_k
\end{equation}
Consider the system state at $t^{*-}$ immediately prior to $A_{p^*}$ being granted $R_{(p^*)}^{\text{first}}$. Because $t_{p_m}^{\text{entry}} < t^*$ for every other cycle member $m \ne p^*$, $A_{p^*}$'s cycle successor $A_{p_{\text{succ}(p^*)}}$ ($p_{\text{succ}(p^*)} \ne p^*$ since $L \ge 2$) had already entered its critical section and was actively holding at least $R_{(p_{\text{succ}(p^*))}}^{\text{first}}$ at $t^{*-}$, so $\text{Held}(A_{p_{\text{succ}(p^*)}}, t^{*-}) \ne \emptyset$.

By Eq.~\eqref{eq:footprint_overlap}, there exists at least one shared partition $P_{\text{shared}} \in \mathcal{F}(T_{p^*}) \cap \mathcal{F}(T_{p_{\text{succ}(p^*)}})$. By the atomic registration invariant (Section 3.2), both $A_{p^*}$ and $A_{p_{\text{succ}(p^*)}}$ belonged to $\mathcal{U}(P_{\text{shared}}, t^{*-})$ at $t^{*-}$. Consequently, the partition priority ceiling of $P_{\text{shared}}$ at $t^{*-}$ satisfied:
\begin{equation}
\begin{aligned}
\Pi(P_{\text{shared}}, t^{*-}) &= \max_{A_q \in \mathcal{U}(P_{\text{shared}}, t^{*-})} \Pi_q^{\max} \\
&\ge \max\big(\Pi_{p^*}^{\max},\, \Pi_{p_{\text{succ}(p^*)}}^{\max}\big) \ge \Pi_{p^*}^{\max}
\end{aligned}
\end{equation}
Because $A_{p_{\text{succ}(p^*)}} \ne A_{p^*}$ satisfied $\text{Held}(A_{p_{\text{succ}(p^*)}}, t^{*-}) \ne \emptyset$ and $P_{\text{shared}} \in \mathcal{F}(T_{p^*}) \cap \mathcal{F}(T_{p_{\text{succ}(p^*)}})$, $A_{p_{\text{succ}(p^*)}} \in \mathcal{K}_{\text{ext}}(A_{p^*}, t^{*-})$. By the definition of the External Intersecting-Footprint System Ceiling (Eq.~\eqref{eq:ext_ceiling_def}), the external ceiling confronting $A_{p^*}$ at $t^{*-}$ satisfied:
\begin{equation}
\label{eq:ext_ceil_bound}
C_{-A_{p^*}}^*(t^{*-}; \mathcal{F}(T_{p^*})) \ge \Pi(P_{\text{shared}}, t^{*-}) \ge \Pi_{p^*}^{\max}
\end{equation}
Simultaneously, because $A_{p^*}$ held no locks at $t^{*-}$ ($\text{Held}(A_{p^*}, t^{*-}) = \emptyset$), it had zero incoming wait edges ($\text{Waiters}(A_{p^*}, t^{*-}) = \emptyset$), so its effective priority equaled its own upper-envelope preemption level: $\Pi_{p^*}^{\text{eff}}(t^{*-}) = \Pi_{p^*}^{\max}$. Moreover, because $\text{Held}(A_{p^*}, t^{*-}) = \emptyset$, the guarded pass-through disjunct of the EPCP Ceiling Admissibility Rule (Eq.~\eqref{eq:ceiling_rule}) evaluated to false at $t^{*-}$. Therefore, $A_{p^*}$ could be granted $R_{(p^*)}^{\text{first}}$ at $t^*$ if and only if the first disjunct of Eq.~\eqref{eq:ceiling_rule} held strictly:
\begin{equation}
\label{eq:strict_dom}
\Pi_{p^*}^{\max} = \Pi_{p^*}^{\text{eff}}(t^{*-}) > C_{-A_{p^*}}^*(t^{*-}; \mathcal{F}(T_{p^*}))
\end{equation}
Combining Eq.~\eqref{eq:ext_ceil_bound} and Eq.~\eqref{eq:strict_dom} yields $\Pi_{p^*}^{\max} > C_{-A_{p^*}}^*(t^{*-}; \mathcal{F}(T_{p^*})) \ge \Pi_{p^*}^{\max}$, i.e., $\Pi_{p^*}^{\max} > \Pi_{p^*}^{\max}$, which is a direct mathematical contradiction. Thus, no cycle can ever form, and $\mathcal{G}_{\text{wait}}(t)$ remains a strict DAG for all $t \ge 0$.
\end{proof}

\subsection{Theorem 2: Bounded Priority Inversion}
\begin{theorem}[Bounded Priority Inversion]
Under EPCP, a high-priority agent $A_H$ can be blocked by lower-priority agents ($\Pi_L^{\max} < \Pi_H^{\max}$) for at most the duration of a single critical section per mutually disjoint partition component in $\mathcal{F}(T_H)$ (at most one lower-priority agent across all mutually overlapping footprints, and at most $|\mathcal{F}(T_H)|$ concurrent lower-priority critical sections across disjoint partitions).
\end{theorem}

\begin{proof}
Suppose agent $A_H$ requests its first lock at time $t$ with priority $\Pi_H^{\max}$ and is suspended under either Rule 2 (direct contention) or Rule 3 (ceiling preemption) by a lower-priority agent $A_L$ ($\Pi_L^{\max} < \Pi_H^{\max}$) whose footprint intersects $\mathcal{F}(T_H)$ at shared partition $P_m \in \mathcal{F}(T_H) \cap \mathcal{F}(T_L)$ with $\Pi(P_m, t) \ge \Pi_H^{\max}$. First, among any set of lower-priority agents whose footprints overlap on $P_m$ (or overlap with one another), at most \textit{one} such lower-priority agent can hold a lock at time $t$: if two overlapping lower-priority agents $A_{L_1}$ and $A_{L_2}$ ($\mathcal{F}(T_{L_1}) \cap \mathcal{F}(T_{L_2}) \ne \emptyset$) both held locks, the second to enter ($t_{L_2}^{\text{entry}} > t_{L_1}^{\text{entry}}$) had $\text{Held}(A_{L_2}, t_{L_2}^{\text{entry}-}) = \emptyset$ and would have been required by Eq.~\eqref{eq:ceiling_rule} to satisfy $\Pi_{L_2}^{\max} > C_{-A_{L_2}}^*(t_{L_2}^{\text{entry}-}; \mathcal{F}(T_{L_2})) \ge \Pi(P_m, t_{L_2}^{\text{entry}-}) \ge \Pi_{L_2}^{\max}$, which is impossible whenever $\mathcal{K}_{\text{ext}}(A_{L_2}, t_{L_2}^{\text{entry}-}) \ne \emptyset$. Across at most $|\mathcal{F}(T_H)|$ mutually disjoint partitions, at most one pre-existing lower-priority holder per disjoint partition can exist, and they execute concurrently in parallel. Second, by Unified Transitive Priority Inheritance (Eq.~\eqref{eq:inheritance}), each blocking $A_L$ immediately inherits $\Pi_L^{\text{eff}}(t) \ge \Pi_H^{\max}$ (or if another even higher-priority waiter $A_{H'}$ with $\Pi_{H'}^{\max} > \Pi_H^{\max}$ is also waiting on $A_L$, then $A_L$ inherits the maximum waiter ceiling $\Pi_L^{\text{eff}}(t) = C^*(t; \mathcal{F}(T_L)) \ge \Pi_{H'}^{\max} > \Pi_H^{\max} > \Pi_L^{\max}$, and $A_H$ waits for $A_L$ plus any higher-priority transactions $A_{H'}$, which is standard high-priority preemption rather than priority inversion). Because $\Pi_L^{\text{eff}}(t) = C^*(t; \mathcal{F}(T_L)) > \Pi_L^{\max}$ and $\text{Held}(A_L, t) \ne \emptyset$, the guarded pass-through clause of Eq.~\eqref{eq:ceiling_rule} allows $A_L$ to acquire any remaining locks in $\mathcal{F}(T_L)$ without secondary ceiling self-blocking, complete its single critical section, and wake the highest-urgency waiter upon commit.
\end{proof}

\subsection{Theorem 3: Conflict Serializability and Starvation-Free Progress}
\begin{theorem}[Serializability and Starvation Freedom]
Every execution schedule permitted under EPCP is conflict serializable, and every active transaction terminates in finite time without deadlock or starvation.
\end{theorem}

\begin{proof}
All locks are acquired during the growth phase and held until transaction commit or domain validation exit (Strict 2PL). By Eswaran et al.~\cite{eswaran1976notions}, any schedule obeying strict two-phase locking is conflict serializable. By Theorem 1, $\mathcal{G}_{\text{wait}}(t)$ is a strict DAG ($0$ deadlock aborts). To prove unconditional starvation freedom even under a continuous arrival stream of deeper ($d_j > d_i$) transactions, recall from Definition 3 that once any waiting transaction $T_i$'s elapsed wait time reaches the finite senior saturation horizon $T_{\text{sat}} = \Omega_{\max}/\gamma_{\text{age}}$, the coordinator atomically promotes \textit{both} its latched dynamic score and its upper-envelope preemption score to $\Pi_{\text{sat}} = \Pi_{\text{base}} + w_d \cdot d_{\max} + w_\Omega \cdot \ln(1 + \Omega_{\max}) + w_c$, so both $\tilde{\Pi}_i(t)$ and $\Pi_i^{\max}$ attain $\Pi_{\text{sat}} - \epsilon_{\text{tie}} \cdot \text{rank}(T_i)$, recomputes $\Pi(P_m, t)$ for all $P_m \in \mathcal{F}(T_i)$, and propagates the promoted $\Pi_i^{\max}$ along $\mathcal{G}_{\text{wait}}(t)$ via Eq.~\eqref{eq:inheritance}. Because arrival ranks $\text{rank}(T_i)$ are strictly increasing with arrival time (and preserved across any footprint expansion), $T_i$'s negative rank tie-breaker $-\epsilon_{\text{tie}} \cdot \text{rank}(T_i)$ is strictly greater than that of every transaction $T_j$ arriving after $T_i$ ($\text{rank}(T_i) < \text{rank}(T_j)$), independent of $T_j$'s initial depth $d_j$ or entropy $\mathcal{H}_j$. Since at most a finite number of transactions arrived prior to $T_i$ and each critical section consists of a finite number of bounded LLM inference and SQL steps, $T_i$ becomes the unique highest-priority transaction across all partitions in $\mathcal{F}(T_i)$ in finite time, acquires its locks, and commits.
\end{proof}

\section{Empirical Evaluation and Benchmark Results}

\subsection{Experimental Architecture and Methodology}
We evaluated EPCP across two complementary regimes on an Apple Silicon M-series workstation (8 CPU cores, APFS storage) fronting a relational SQLite WAL storage engine (\texttt{PRAGMA journal\_mode = WAL; PRAGMA synchronous = NORMAL; PRAGMA busy\_timeout = 60000;}). To prevent SQLite's file-level single-writer lock from artificially serializing multi-step reasoning phases while guaranteeing zero dirty or stale reads, the coordinator maintains a synchronized in-memory mirror of committed row state alongside SQLite WAL: all row- and partition-level lock arbitration, condition-variable suspension ($\text{CV}(R_{\text{req}})$, $\text{CV}_{\text{ceil}}(P_m)$), Step-1 \texttt{Biz-Rule Reject} checks, and intermediate reasoning steps ($\text{Infer}(\phi)$) read the exact latest committed state under held locks and stage mutations in a transaction-local write buffer; once all locks in $T_i$ are held and validated, the final physical SQLite mutation batch (\texttt{BEGIN IMMEDIATE; UPDATE ...; COMMIT;}) flushes to the WAL journal and updates the committed mirror atomically in $\approx 50\text{--}150\text{ }\mu\text{s}$ at the $\text{Commit}$ step:
\begin{enumerate}
    \item \textbf{Regime 1 (High-Frequency Lock-Manager Stress Test, Table~\ref{tab:enterprise_telemetry}):} Isolates raw lock-table arbitration and ceiling condition-variable overhead using in-critical-section CPU-bound cryptographic HMAC-SHA256 policy verification and polynomial risk scoring ($\approx 0.5\text{--}2.0\text{ ms}$ per lock step, $|\mathcal{F}(T_i)| = 2$) across $K \in \{5, 10, 20, 30, 40\}$ concurrent worker threads ($25$ transactions/thread, $125$ to $1{,}000$ transactions/run, repeated across 5 independent random seeds). Prior to each $(K, \text{Protocol})$ run, the database is freshly re-seeded from a canonical snapshot of 10,000 Customer Accounts and 5,000 Inventory Items under heavy Zipfian contention ($\theta = 0.85$, concentrating 85\% of accesses on the top 50 hot accounts and top 30 hot inventory items). In addition to the standard finite-stock snapshot (where hot SKUs naturally experience stock depletion at $K \ge 20$), we execute \textbf{Zero-Depletion Controls across $K \in \{20, 30, 40\}$} with $100\times$ initial balances/stock so $0$ \texttt{Biz-Rule Rejects} occur and 100\% of non-deadlocked transactions execute full 2-step settlements.
    \item \textbf{Regime 2 (High-Latency 500~ms--1,500~ms 2-Step LLM Reasoning Benchmark \& Live Vertex AI Evaluation, Table~\ref{tab:llm_regime}):} Evaluates 2-step agent transactions ($\text{Lock}(R_a) \to \text{Infer}_1(\phi) \to \text{Lock}(R_b) \to \text{Infer}_2(\phi) \to \text{Commit}$, with $|\mathcal{F}(T_i)| = 2$ over $B_{\text{part}}=64$, $d_i \sim \text{Uniform}\{1, 2, 3, 4\}$, initial $\mathcal{H}_i \sim \text{Beta}(2, 5)$, $800\text{ LLM tokens}$ per $\text{Infer}$ step $= 1{,}600\text{ tokens}$ per full 2-step attempt, and uniform $250\text{--}750\text{ ms}$ reasoning latency per step $= 500\text{--}1{,}500\text{ ms}$ total 2-step in-lock reasoning duration per transaction, mean $1.00\text{ s}$, giving a Little's Law zero-wait upper bound of $20.0\text{ Tx/s}$ at $K=20$ and $40.0\text{ Tx/s}$ at $K=40$) across $K \in \{20, 40\}$ threads (5 seeds, $\text{Mean} \pm \text{SD}$). We compare nine protocols: \textbf{S2PL}~\cite{eswaran1976notions}, \textbf{2PL-Wait Promote}~\cite{abbott1992scheduling} (applying transitive epistemic priority inheritance $\tilde{\Pi}_j^{\text{eff}}(t)$ on direct row contention without EPCP's ceiling admission gate), \textbf{Wound-Wait}~\cite{rosenkrantz1978system, corbett2013spanner}, \textbf{Wait-Die}~\cite{rosenkrantz1978system}, \textbf{OCC (Snapshot Read + CAS Commit)}, \textbf{Coarse Shard-Scoped C2PL (\texttt{Shard-C2PL}, $B_{\text{shard}}=8$)}~\cite{bernstein1987concurrency} (acquiring upfront exclusive locks on coarse 8-bucket domain shards), \textbf{Canonical Ordered Locking (Discovery Pre-Pass)} (executing an unlocked speculative $\text{Infer}_1$ pre-pass to discover $R_b$, sorting $\min(R_a, R_b) < \max(R_a, R_b)$, and re-running $\text{Infer}_1$ if $R_a$ mutated before lock acquisition), \textbf{EPCP Ablation (Static $\Pi_i^{\max}$ Only, w/o Live $\tilde{\Pi}_i(t)$)}, and \textbf{Full EPCP}. Finally, we supplement the controlled sweep with a \textbf{Live Google Cloud Vertex AI (\texttt{gemini-2.5-flash}, project \texttt{aniket-personal}) Multi-Agent Evaluation} at $K=10$ concurrent worker threads ($50$ 2-step transactions $= 100$ live Gemini API calls per protocol).
\end{enumerate}

    \item \textbf{Total Elimination of Deadlocks and Token Waste Across All Baselines:} Across all concurrency levels in Table~\ref{tab:enterprise_telemetry} and Table~\ref{tab:llm_regime} (and Figure~\ref{fig:abort_rate}), EPCP recorded \textbf{0 deadlocks} ($0.00\%$ abort rate) and \textbf{0 wasted LLM tokens}. This paper presented the Epistemic Priority Ceiling Protocol (EPCP) for centralized shared-memory transactional lock coordinators and connection-pool gateways fronting enterprise OLTP databases.
